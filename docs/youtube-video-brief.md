# תדריך: סרטון יוטיוב על הרחבת "ישראל" למיקרוביט

המסמך הזה מיועד ל-Claude Code שרץ מקומית, כדי לעזור להפיק סרטון יוטיוב בעברית שמציג את ההרחבה. יש בו כל מה שצריך לדעת על ההרחבה, מבנה מוצע לסרטון, תוכניות הדגמה מוכנות להדבקה, ונקודות שחשוב לא לטעות בהן.

## על ההרחבה בקצרה

- **מה זה:** הרחבה ל-[MakeCode למיקרוביט](https://makecode.microbit.org) שמוסיפה קטגוריה כחולה בשם **ישראל**, עם בלוקים ציוניים-ישראליים.
- **ריפו:** https://github.com/nadaval56/israel-microbit (הענף הראשי: `claude/zen-dijkstra-cmuo2o`).
- **הוספה ב-MakeCode:** ⚙️ ← **הרחבות** ← הדבקת `https://github.com/nadaval56/israel-microbit` בשורת החיפוש.
- **שפה:** כשממשק MakeCode מוגדר לעברית, שמות הבלוקים בעברית. לסרטון כדאי להגדיר את הממשק לעברית.
- **קהל יעד:** מורים ותלמידים בישראל, בעיקר בבית הספר היסודי והחטיבה.
- **קבצים חשובים בריפו:**

  | קובץ | תוכן |
  |---|---|
  | `israel.ts` | סמלים, אנימציות, תמונות נגללות, גופן עברי, ברכות |
  | `songs.ts` | השירים (נוצר מ-`tools/make_songs.py`) |
  | `morse.ts` | מורס עברי |
  | `README.md` | תיעוד מלא בעברית |
  | `icon.png` | אייקון: מיקרוביט על דגל ישראל (טוב לכרטיס פתיחה ולתמונה ממוזערת) |

## מבנה מוצע לסרטון (6–8 דקות)

לכל סצנה יש תוכנית הדגמה ב-JavaScript. מדביקים אותה בעורך ה-JavaScript של MakeCode, אחרי שההרחבה נוספה לפרויקט, ועוברים לתצוגת בלוקים כדי לצלם את הבלוקים.

### 1. פתיחה (20–30 שניות)
כרטיס פתיחה עם `icon.png` וכותרת, למשל: "הרחבת ישראל למיקרוביט: דגל, עברית, שירי חגים ומורס". משפט אחד על מה ההרחבה נותנת.

### 2. איך מוסיפים את ההרחבה (30–45 שניות)
הקלטת מסך: פרויקט חדש ← ⚙️ ← הרחבות ← הדבקת הקישור ← הקטגוריה הכחולה "ישראל" מופיעה. כדאי להראות גם החלפת שפת הממשק לעברית.

### 3. עברית על המסך (כדקה)
```javascript
israel.showHebrew("שלום כיתה ד'")
israel.showGreeting(HebrewGreeting.AmIsraelChai)
basic.showNumber(israel.israelAge(2026))
```
- **מה לספר:** למיקרוביט אין גופן עברי, אז ההרחבה כוללת גופן משלה בגודל 5×5. הטקסט נגלל בכיוון הקריאה העברי, ומספרים נשארים משמאל לימין.

### 4. סמלים, אנימציות ותמונות נגללות (כדקה וחצי)
```javascript
israel.showSymbol(IsraelSymbol.StarOfDavid)
basic.pause(1000)
israel.playAnimation(IsraelAnimation.StarOfDavid)
israel.scrollPicture(IsraelPicture.Flag)
israel.scrollPicture(IsraelPicture.Menorah)
for (let night = 1; night <= 8; night++) {
    israel.scrollHanukkiah(night, 80)
}
```
- **מה לספר:** תמונה רחבה לא נכנסת במסך של 5×5, ולכן היא נגללת. הלולאה על הלילות היא דוגמה טובה לשילוב חשבון ותכנות.

### 5. שירים (כדקה)
```javascript
input.onButtonPressed(Button.A, function () {
    israel.showSymbol(IsraelSymbol.StarOfDavid)
    israel.playHatikvah()
})
input.onButtonPressed(Button.B, function () {
    israel.showSymbol(IsraelSymbol.Dreidel)
    israel.playSong(IsraeliSong.MaozTzur, 120)
})
```
- **מה להראות:** את ה-"+" שבבלוק, שפותח את בחירת המהירות באחוזים.
- **זכויות יוצרים:** ראו סעיף "נקודות זהירות". בסרטון כדאי לנגן רק שירים חופשיים.

### 6. מורס עברי (2–3 דקות, הסצנה המרכזית)
**6א. מצפין:** טקסט חופשי, אפילו משפט שלם, הופך לצפצופים והבהובים.
```javascript
israel.setMorseSpeed(120)
israel.playMorse("שלום")
basic.showString(israel.textToMorse("SOS"))
```

**6ב. טלגרף ברדיו בין שני מיקרוביטים.** כשמשתמשים ברדיו, הסימולטור של MakeCode מציג שני לוחות אוטומטית, וזה מצוין לצילום. אותה תוכנית בשני הלוחות:
```javascript
israel.setMorseRadioGroup(7)
input.onButtonPressed(Button.A, function () {
    israel.sendDot()
})
input.onButtonPressed(Button.B, function () {
    israel.sendDash()
})
input.onButtonPressed(Button.AB, function () {
    israel.endLetter()
    israel.showHebrew(israel.lastLetterSent())
})
input.onGesture(Gesture.Shake, function () {
    israel.endWord()
})
israel.onMorseReceived(function (signal) {
    israel.showMorseSignal(signal)
    israel.playMorseSignal(signal)
})
```
- **מה לספר:** הקולט רק מצפצף ומהבהב, והילדים מפענחים בעצמם. הבלוקים נפרדים, כדי שהילדים יבנו את הטלגרף שלהם עם כל קלט שהם רוצים.

**6ג. ילדים בונים מפענח.** מראים את הקוד, לא חובה להריץ:
```javascript
let code = ""
let letters = ["א", "ב", "ג", "ד", "ה", "ו", "ז", "ח", "ט", "י", "כ", "ל", "מ", "נ", "ס", "ע", "פ", "צ", "ק", "ר", "ש", "ת"]
israel.setMorseRadioGroup(7)
israel.onMorseReceived(function (signal) {
    israel.playMorseSignal(signal)
    if (signal == israel.morseSignal(MorseSignal.Dot) || signal == israel.morseSignal(MorseSignal.Dash)) {
        code = "" + code + signal
    } else if (signal == israel.morseSignal(MorseSignal.LetterEnd)) {
        for (let letter of letters) {
            if (israel.textToMorse(letter) == code) {
                israel.showHebrew(letter)
            }
        }
        code = ""
    }
})
```
- **מה לספר:** הטריק הוא הבלוק "קוד מורס של", שבזכותו אין צורך לבנות טבלה של 22 אותיות.

### 7. סיום (20–30 שניות)
קישור להרחבה בתיאור הסרטון, רעיונות לשימוש בכיתה לפי חגים, וקריאה לשתף פרויקטים.

## נקודות זהירות

1. **זכויות יוצרים בסרטון יוטיוב.** חלק מהשירים מוגנים (ראו טבלה). מערכת Content ID של יוטיוב עלולה לזהות מנגינה ולסמן את הסרטון. לכן כדאי לנגן בסרטון רק שירים חופשיים: התקווה, מעוז צור, דיינו, חג פורים ובר יוחאי. את השאר אפשר להזכיר ולהראות ברשימה בלי לנגן.
2. **סימולטור מול לוח אמיתי.** הלדים של המיקרוביט אדומים, והכחול הוא רק צבע הבלוקים. עוצמות האור השונות נראות טוב יותר על לוח אמיתי מאשר בסימולטור. אם מצלמים לוח אמיתי, צריך לצלם בתאורה עמומה ובחשיפה נמוכה.
3. **באג עברית שתוקן.** בגרסאות מוקדמות, טקסט עברי לא הופיע על הלוח האמיתי, רק בסימולטור. זה תוקן בקומיט `f1ac229`. לפני הצילום צריך להסיר ולהוסיף מחדש את ההרחבה ב-MakeCode, כדי לקבל את הגרסה העדכנית.
4. **מה לא נבדק על חומרה.** הרדיו והטלגרף נבדקו בהידור ובהדמיה, אבל לא על שני מיקרוביטים פיזיים. לפני שמצלמים אותם על לוחות אמיתיים כדאי לנסות.
5. **מיקרוביט V1.** הכל נכנס בזיכרון של V1, אבל בקושי (כ-2.5KB פנויים כשמשתמשים בכל הבלוקים יחד). לוגו המגע קיים רק ב-V2.
6. **אירוע רדיו תפוס.** הבלוק "כשמתקבל אות מורס" משתמש באירוע הרדיו "כשמתקבל ערך", ולכן אין לשלב בתוכנית בלוק כזה משלך.
7. **ההרחבה לא מאושרת רשמית.** לכן היא לא מופיעה בחיפוש הרגיל של MakeCode, ומוסיפים אותה בהדבקת הקישור המלא. גם האייקון לא יופיע בכרטיס שלה בחיפוש.

## הצעות להפקה

- **הקלטת מסך:** OBS או כל מקליט מסך, ברזולוציה של 1080p. כדאי להגדיל את גודל הבלוקים ב-MakeCode (Ctrl ו-+) כדי שיהיו קריאים בסרטון.
- **קריינות:** בעברית, בקצב רגוע, עם הסבר קצר לפני כל הדגמה.
- **כותרות על המסך:** שם הבלוק בעברית כשהוא מופיע לראשונה.
- **תמונה ממוזערת:** `icon.png` מוגדל, עם כותרת קצרה כמו "מיקרוביט בעברית!" או "מורס עברי במיקרוביט".
- **תיאור הסרטון:** קישור לריפו, הוראות הוספה בשלוש שורות, וחותמות זמן לכל סצנה.
- **פרקים מוצעים:** פתיחה, הוספת ההרחבה, עברית על המסך, סמלים ואנימציות, שירים, מורס עברי, סיכום.
